# Modes

Pane has seven modes. `Cmd+/` cycles between the three you use most: conversation, files, and terminal.

## Conversation

The primary mode. Chat with the model — ask questions, request changes, review diffs. The model reads your project, runs commands, edits files, and commits. You steer.

## Files

File tree on the left, Ace editor on the right. Supports 35+ languages with syntax highlighting. Manual edits when you want them — but most of the time the model writes the code and you review it here.

## Terminal

Multi-tab PTY terminal. Shared with the model — it can run commands here and so can you. Useful for watching the model work, running builds, or stepping in directly.

## Git

Staged diffs, commit history, branch switching. Every AI edit is a commit. You can browse the history, see what changed, and revert anything.

## Mind

A freeform thought dump. Type what's on your mind. Mark items done. Move on. Think of it as a scratchpad that doesn't disappear — the model can also reference it.

## Lens

Automated code review. "Punks" scan your codebase and flag issues — dead code, complexity spikes, potential bugs. Configurable scan depth and severity thresholds.

## History

Every AI edit is recorded. Browse the change log, see diffs side-by-side, revert any change with one click. Nothing the model does is permanent unless you want it to be.
