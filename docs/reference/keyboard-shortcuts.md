# Keyboard shortcuts

All shortcuts are customizable in **Profile → Keybindings**. These are the defaults.

## Navigation

| Shortcut | Action |
|---|---|
| `⌘/` | Toggle chat / editor |
| `⌘B` | Toggle sidebar |
| `⌘P` | Search files (fuzzy finder) |
| `⇧⌘F` | Search in files |
| `⌘K` | Focus chat |

## Files & editor

| Shortcut | Action |
|---|---|
| `⌘N` | New file |
| `⌘,` | Settings |

## Theme & display

| Shortcut | Action |
|---|---|
| `⇧⌘T` | Cycle theme |
| `⌘=` | Increase font size |
| `⌘-` | Decrease font size |
| `⌘0` | Reset font size |

## Other

| Shortcut | Action |
|---|---|
| `⌘M` | Open Mind mode |

::: tip
All shortcuts can be rebound in **Profile → Keybindings**. Reserved shortcuts (`⌘Q`, `⌘W`, `⌘C`, `⌘V`, `⌘X`, `⌘A`, `⌘Z`, `⌘H`, `⌘M`) cannot be overridden.
:::
