# Pane

The lightest AI-native coding environment.

Multiple threads. Multiple models. One window. A conversation, a file editor, and a terminal — nothing else.

---

### Threads

Each thread is an independent AI session. Its own history. Its own model. Its own context. Its own terminal state. Switch with Cmd+1/2/3. Pick up where you left off.

### Models

Claude. Gemini. DeepSeek. OpenRouter. Pick the right tool for the work. Switch mid-session. The brain is swappable; the context stays.

### Modes

Three. Conversation. File editor. Terminal. Toggle with a keystroke. That's all you get, because that's all you need.

### Memory

Decisions, patterns, and learnings persist across sessions. Every thread starts warm — no cold starts, no re-explaining.

---

### Stack

Electron 40 / React 19 / Tailwind v4 / Zustand v5 / node-pty

macOS only.

### Shortcuts

| Key | Action |
|-----|--------|
| `Cmd+/` | Toggle conversation / editor |
| `Cmd+1-9` | Switch threads |
| `Cmd+B` | Toggle sidebar |
| `Cmd+P` | Open file |
| `Cmd+K` | Focus chat |
| `Cmd+Shift+F` | Search in files |
